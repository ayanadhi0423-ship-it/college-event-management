## Objective
Develop a responsive single-page college event management website using HTML5, CSS3 and JavaScript, following the college assignment brief.

## Technologies
HTML5 semantic elements and forms; CSS3 Grid, Flexbox, media queries, transitions and CSS variables; JavaScript DOM manipulation, arrays, event listeners, regular-expression validation, timers and localStorage.

## Sections
1. **Home:** Institute/department branding, sticky navigation, introduction, call-to-action links, live countdown and IST clock.
2. **Events:** Six example events with name, date, venue, category and description; category filtering.
3. **Registration:** Name, 10-digit roll, department, email, phone, gender and event fields, with JavaScript validation.
4. **Gallery:** Six SVG illustrations, Grid layout, hover zoom and captions.
5. **About us:** Department introduction and coordinator placeholders.
6. **Contact:** Address, official website link and validated feedback form.

## JavaScript functionality
- Countdown to the next future event
- Live IST digital clock
- Event filtering and dynamic rendering from a single `EVENTS` array
- Registration and feedback validation
- Dark/light mode with persistent theme choice
- Mobile hamburger navigation

## Responsiveness
Desktop: two-column hero and three-column gallery. Tablet: one-column hero and two-column gallery. Mobile: collapsible navigation and single-column gallery/forms.

## Limitations
This is a frontend demonstration: submissions are saved only in the current browser via localStorage, not sent to a central server. Dates and venues are illustrative sample data, and coordinator details require confirmation. Official event photography may be substituted with permission.

## Conclusion
The project demonstrates how HTML, CSS and JavaScript combine to build a functional, accessible and responsive college event website.
